## About This Repository

This repository documents my learning journey through fundamental data structures and algorithms using C++.

I am following the textbook chapter by chapter, solving its practice problems and exercises, and organizing my solutions into separate directories based on each chapter.

The primary goal is to strengthen my understanding of data structures, improve problem-solving skills, and maintain a well-organized collection of C++ implementations for future reference.

## How to Run

Compile a C++ source file using G++:

```bash
g++ filename.cpp -o output
```

Run the compiled program:

```bash
./output
```

On Windows, run:

```bash
output.exe
```
